# Workout Tracker — версия с базой упражнений

Мобильное веб-приложение для учета тренировок, питания, веса и прогресса.

## Что нового

- Большая база силовых упражнений с подсказками по технике.
- В карточках упражнений есть карта мышц: основная и дополнительная нагрузка.
- Кнопка «Как делать» открывает инструкцию: шаги выполнения, советы и частые ошибки.
- Таймер отдыха переделан в круговой циферблат.
- На главном экране карточка «Тренировка» переименована в «Треня» и больше не ломает блок на мобильном.
- Сканер штрихкодов теперь использует `BarcodeDetector`, если браузер его поддерживает, а в Safari/Firefox пытается подключить ZXing fallback.
- Добавлен ручной ввод штрихкода на случай, если камера/сканер не сработают.

## Запуск локально

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Деплой на Vercel

1. Загрузите файлы проекта в GitHub.
2. Подключите репозиторий к Vercel.
3. Framework Preset: `Vite`.
4. Build Command: `npm run build`.
5. Output Directory: `dist`.

## Важно про сканер

- Камера работает только на HTTPS или localhost.
- На iPhone/Safari встроенный `BarcodeDetector` обычно недоступен, поэтому приложение использует fallback через ZXing.
- Если камера не распознает код, можно ввести штрихкод вручную.
- Данные продукта подтягиваются из Open Food Facts, поэтому точность зависит от заполненности базы.
