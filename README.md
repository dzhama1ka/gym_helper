# Мой фитнес-дневник — тренировки, профиль и питание

Это Vite + React проект для Vercel.

## Что есть в этой версии

### Тренировки

- Силовые упражнения: подходы, повторы, вес, заметки.
- Кардио: время, интенсивность, дистанция, ккал.
- Кардио-ккал считаются по MET-формуле: `MET × 3.5 × вес_кг / 200 × минуты`.
- Вес для кардио берется из профиля пользователя.

### Профиль вместо старых статов

- Рост, вес, желаемый вес.
- Возраст, пол и уровень активности.
- Расчет BMR по Mifflin–St Jeor.
- Расчет TDEE по коэффициенту активности.
- Цель калорий на день.
- Ориентир по БЖУ.
- Записи веса по датам.
- SVG-график изменения веса.
- Расчет темпа изменения веса и примерного энергетического сдвига.

### Питание

- Дневник калорий по выбранной дате.
- Приемы пищи: завтрак, обед, ужин, перекус.
- Быстрая база продуктов.
- Ручной ввод продуктов по этикетке: ккал, белки, жиры, углеводы на 100 г.
- Автоматический пересчет на граммовку.
- Сводка за день по калориям и БЖУ.
- Кнопка «Меню на день» добавляет пример сбалансированного меню под цель калорий.
- Сканер штрихкода через камеру и Open Food Facts.

## Важно про питание

Расчеты в приложении — ориентиры для самоконтроля, а не медицинские назначения. При заболеваниях, беременности, расстройствах пищевого поведения, приеме лекарств или резких изменениях веса нужен врач/диетолог.

## Как запустить локально

```bash
npm install
npm run dev
```

## Как залить на Vercel

1. Загрузи папку проекта в GitHub.
2. В Vercel выбери **Add New Project**.
3. Framework Preset: **Vite**.
4. Build Command: `npm run build`.
5. Output Directory: `dist`.
6. Нажми **Deploy**.

## Где менять логику

Основной файл:

```txt
src/main.jsx
```

Там находятся:

- список силовых упражнений: `strengthExercises`;
- настройки кардио: `cardioProfiles`;
- расчет ккал кардио: `calculateExerciseCalories`;
- профиль и расчеты питания: `calculateNutritionPlan`;
- список продуктов: `foodDatabase`;
- пример меню: `sampleMenu`;
- сканер штрихкода: `startScanner` и `fetchOpenFoodFactsProduct`.

## Где менять дизайн

```txt
src/styles.css
```

Там находятся цвета, карточки, кнопки, адаптация под телефон и график.
