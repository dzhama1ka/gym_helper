# Мои тренировки — версия с кардио

Это Vite + React проект для Vercel.

## Что изменилось

- Добавлен тип упражнения: **Силовое** или **Кардио**.
- При выборе кардио-упражнения поля меняются:
  - время;
  - сложность / настройка;
  - дистанция;
  - ккал.
- Для кардио добавлен расчет ккал по MET:
  `MET × 3.5 × вес_кг / 200 × минуты`.
- В статистику добавлены:
  - кардио-минуты;
  - ккал кардио;
  - дистанция;
  - силовой объем.

## Как запустить локально

```bash
npm install
npm run dev
```

## Как залить на Vercel

1. Загрузи папку проекта в GitHub.
2. В Vercel выбери **Add New Project**.
3. Framework Preset: **Vite**.
4. Build Command: `npm run build`.
5. Output Directory: `dist`.
6. Нажми **Deploy**.

## Где менять логику

Основной файл:

```txt
src/main.jsx
```

Там находятся:

- список силовых упражнений: `strengthExercises`;
- настройки кардио: `cardioProfiles`;
- расчет ккал: `calculateCalories`;
- логика формы: `addEntry`;
- карточки упражнений: `ExerciseCard`.

## Где менять дизайн

```txt
src/styles.css
```

Там находятся цвета, карточки, кнопки, адаптация под телефон.
