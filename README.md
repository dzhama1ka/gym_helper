# Мои тренировки — мобильное веб-приложение

Это готовый проект на React + Vite для учета тренировок.

## Что умеет

- Добавлять упражнения по датам
- Записывать подходы, повторы, вес и заметки
- Смотреть историю тренировок
- Искать упражнения
- Смотреть статистику и личные рекорды
- Сохранять данные в браузере через localStorage

## Как запустить локально

1. Установи Node.js: https://nodejs.org/
2. Открой терминал в папке проекта
3. Выполни команды:

```bash
npm install
npm run dev
```

После этого приложение откроется по локальному адресу, который покажет терминал.

## Как выложить на Vercel

1. Создай новый репозиторий на GitHub.
2. Загрузи туда все файлы из этой папки.
3. Зайди на https://vercel.com/ и нажми Add New Project.
4. Выбери свой GitHub-репозиторий.
5. Framework Preset: Vite.
6. Build Command: `npm run build`.
7. Output Directory: `dist`.
8. Нажми Deploy.

После деплоя Vercel даст ссылку вида `https://имя-проекта.vercel.app`.
Эту ссылку можно открыть с телефона.

## Важно

Сейчас данные хранятся только в браузере конкретного устройства.
Если открыть приложение на другом телефоне, там будет отдельная история.
Чтобы синхронизировать данные между устройствами, нужно добавить базу данных и авторизацию.
