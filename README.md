# Мой фитнес-дневник — smart версия

Это Vite + React проект для Vercel.

## Что добавлено в этой версии

### Главный экран «Сегодня»

- Сводка по калориям, БЖУ, тренировке, кардио-ккал и весу.
- Быстрые действия: добавить тренировку, добавить еду, меню на день, таймер отдыха.
- Превью сегодняшних упражнений и приемов пищи.

### Тренировки

- Силовые упражнения: подходы, повторы, вес, заметки.
- Кардио: время, интенсивность, дистанция, ккал.
- Кардио-ккал считаются по MET-формуле: `MET × 3.5 × вес_кг / 200 × минуты`.
- Вес для кардио берется из профиля пользователя.
- Шаблоны тренировок: грудь+трицепс, спина+бицепс, ноги, full body, кардио.
- Таймер отдыха 60/90/120/180 секунд.

### Питание

- Дневник калорий по выбранной дате.
- Приемы пищи: завтрак, обед, ужин, перекус.
- Быстрая база продуктов и ручной ввод продукта по этикетке.
- Избранные продукты.
- Копирование питания со вчера.
- Сохранение текущего дня как меню и повторное применение меню.
- Сканер штрихкода через камеру и Open Food Facts.

### Прогресс

- Отдельный раздел прогресса по упражнениям.
- График выбранного упражнения.
- История тренировок с поиском.

### Профиль

- Рост, вес, желаемый вес.
- Возраст, пол и уровень активности.
- Расчет BMR по Mifflin–St Jeor.
- Расчет TDEE по коэффициенту активности.
- Цель калорий на день и ориентир по БЖУ.
- График изменения веса и расчет темпа изменения веса.

## Установка

```bash
npm install
npm run dev
```

## Деплой на Vercel

1. Загрузите файлы проекта в GitHub.
2. Подключите репозиторий в Vercel.
3. Framework Preset: Vite.
4. Build Command: `npm run build`.
5. Output Directory: `dist`.

## Важно

Расчеты в приложении — ориентиры для самоконтроля, а не медицинские назначения. При заболеваниях, беременности, расстройствах пищевого поведения, приеме лекарств или резких изменениях веса нужен врач/диетолог.
